# 📘 Curso-Livro de Python — Do Zero ao Avançado

**Autor: Domingos Ferraz Fonseca**

Livro-curso em português simples, com imagens, exercícios, desafios e projetos.

## Método de cada aula
1. Explicação simples.
2. Exemplo de código.
3. Imagem ou diagrama.
4. Exercício guiado.
5. Exercícios de prática.
6. Desafio.
7. Revisão.

## Caminho
Início absoluto → fundamentos → lógica → funções → estruturas de dados → POO → ficheiros e módulos → APIs e bases de dados → testes → Python avançado → projetos → nível profissional.

O conteúdo será construído em volumes para manter qualidade e navegação.
