## 🗺️ Como estudar

Siga os volumes pela ordem. Em cada aula:

1. Leia a explicação.
2. Observe o diagrama.
3. Execute e altere os exemplos.
4. Faça o exercício guiado.
5. Resolva os exercícios de prática.
6. Tente o desafio.
7. Faça a revisão antes de avançar.
