## O que é Machine Learning?

Machine Learning (ML) é uma área da computação em que sistemas aprendem padrões a partir de dados.

Na programação tradicional, escrevemos regras. Em ML, fornecemos exemplos e um algoritmo aprende uma relação útil entre entradas e resultados.

![Introdução ao ML](../IMAGENS/16_01_introducao_ml.svg)

### Ideias fundamentais

- **Dados:** exemplos usados pelo sistema.
- **Modelo:** estrutura que aprende padrões.
- **Previsão:** resultado produzido para novos dados.

Fluxo: dados → treino → modelo → novos dados → previsão.

Na aprendizagem supervisionada, os exemplos possuem uma resposta conhecida. Exemplo: características de uma casa → preço.
