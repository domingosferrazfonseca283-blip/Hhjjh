## 2. Exemplo prático

~~~python
alunos = [{"nome": "Ana", "nota": 15}, {"nome": "Rui", "nota": 9}]
for aluno in alunos:
    print(aluno["nome"], aluno["nota"])
~~~

Leia o exemplo devagar. Depois execute e faça uma pequena alteração para descobrir o que muda.
