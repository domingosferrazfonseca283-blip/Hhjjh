## 1. Comparar é perguntar

Podemos perguntar ao Python se uma coisa é maior, menor ou igual a outra.

Exemplo:

```python
print(10 > 5)
```

O resultado é:

```
True
```

## 2. Principais comparadores

| Símbolo | Pergunta |
|---|---|
| `>` | é maior? |
| `<` | é menor? |
| `>=` | é maior ou igual? |
| `<=` | é menor ou igual? |
| `==` | é igual? |
| `!=` | é diferente? |

## 3. Atenção ao `==`

Para comparar usamos:

```python
idade == 12
```

Um único `=` serve para atribuir um valor:

```python
idade = 12
```

Esta diferença é muito importante.
