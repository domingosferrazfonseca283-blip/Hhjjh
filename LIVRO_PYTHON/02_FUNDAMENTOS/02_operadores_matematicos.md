## 1. Python também é uma calculadora

Podemos fazer contas diretamente:

```python
print(2 + 3)
print(10 - 4)
print(5 * 2)
print(20 / 4)
```

## 2. Os operadores

| Operador | Significado |
|---|---|
| `+` | soma |
| `-` | subtração |
| `*` | multiplicação |
| `/` | divisão |
| `//` | divisão inteira |
| `%` | resto da divisão |
| `**` | potência |

## 3. Exemplos

```python
print(10 + 5)
print(10 - 5)
print(10 * 5)
print(10 / 5)
```

## 4. O resto da divisão

O operador `%` mostra o resto.

```python
print(10 % 3)
```

Resultado:

```
1
```

Porque 10 dividido por 3 deixa resto 1.

## 5. Potência

```python
print(2 ** 3)
```

Resultado:

```
8
```

É como dizer 2 × 2 × 2.
