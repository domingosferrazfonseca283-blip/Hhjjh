## 1. Quatro ferramentas

Agora conhecemos quatro formas importantes de guardar dados:

| Estrutura | Ideia principal |
|---|---|
| lista | vários itens que podem mudar |
| tupla | vários itens que normalmente não mudam |
| set | valores únicos |
| dicionário | chave + valor |

## 2. Como escolher?

Pergunte:

**Preciso de uma sequência que muda?**

Use uma lista.

**Preciso guardar dados agrupados que não devem mudar?**

Uma tupla pode ser adequada.

**Quero evitar valores repetidos?**

Use um conjunto.

**Tenho informações com nomes ou etiquetas?**

Use um dicionário.

## Exercício guiado

Escolha a melhor estrutura para cada caso:

1. lista de tarefas;
2. coordenadas de um ponto;
3. conjunto de números únicos;
4. cadastro de estudante.

Depois explique sua escolha.

## Exercícios

Crie exemplos próprios para cada estrutura.

## Desafio ⭐

Imagine que você está criando uma pequena biblioteca. Decida onde guardar:

- lista de livros;
- dados fixos de um livro;
- categorias sem repetição;
- informações detalhadas de cada livro.

Não existe apenas uma solução possível. O importante é justificar sua escolha.

## Revisão

A estrutura certa deixa o programa mais organizado e fácil de entender.
