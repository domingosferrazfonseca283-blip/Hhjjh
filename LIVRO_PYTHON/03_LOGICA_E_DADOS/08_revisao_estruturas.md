## Revisão geral

Neste bloco aprendemos:

- listas;
- `for` com listas;
- métodos de listas;
- tuplas;
- dicionários;
- conjuntos;
- escolha da estrutura adequada.

## Exercício 1 — Lista

Crie uma lista de cinco números e:

- mostre o maior;
- mostre o menor;
- calcule a soma.

## Exercício 2 — Dicionário

Crie um cadastro de estudante e mostre todos os campos.

## Exercício 3 — Set

Crie duas listas com alguns valores repetidos. Transforme-as em conjuntos e observe a diferença.

## Exercício 4 — Misturando estruturas

Crie uma lista de dicionários:

```python
alunos = [
    {"nome": "Ana", "nota": 8},
    {"nome": "João", "nota": 7}
]
```

Depois percorra a lista e mostre o nome e a nota de cada aluno.

## Desafio ⭐ — Mini cadastro

Crie um pequeno programa de cadastro.

Cada pessoa deve ter:

- nome;
- idade;
- cidade.

Guarde cada pessoa em um dicionário e coloque os dicionários dentro de uma lista.

Depois use `for` para mostrar todos os cadastros.
