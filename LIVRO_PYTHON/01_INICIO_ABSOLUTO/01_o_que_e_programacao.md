## 1. A ideia mais simples

Programar é escrever instruções para um computador.

Pense numa receita: primeiro fazemos uma coisa, depois outra, e assim por diante. Um programa também é uma sequência de passos.

![Pessoa, instruções e computador](../../IMAGENS/01_pessoa_instrucoes_computador.svg)

## 2. O computador não adivinha

“Faça algo bonito” é uma ordem vaga. Um programa precisa de instruções claras.

Exemplo:

```python
print("Olá!")
```

Aqui pedimos ao Python para mostrar uma mensagem.

## 3. O que é Python?

Python é uma linguagem de programação. Nós escrevemos código Python e o interpretador executa esse código.

## 4. Primeiro contacto

```python
print("Olá, mundo!")
print("Estou a aprender Python.")
```

Cada `print()` mostra informação.

![Exemplo de print](../../IMAGENS/01_codigo_print.svg)

## Exercício guiado

Complete:

```python
print("O meu nome é ______.")
print("Estou a aprender ______.")
```

## Exercícios

**1.** Mostre três frases sobre si.

**2.** Mostre o nome de uma cidade.

**3.** Escreva uma mensagem de incentivo.

**4.** Use cinco comandos `print()`, um por linha.

## Desafio

Crie um programa que mostre o seu nome, o que está a aprender e uma meta.

## Revisão

- Programar é dar instruções.
- Python é uma linguagem de programação.
- `print()` apresenta informação.
- Computadores precisam de instruções claras.
