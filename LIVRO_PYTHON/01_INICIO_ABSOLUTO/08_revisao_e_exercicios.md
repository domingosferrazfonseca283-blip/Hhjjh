## 1. O que já aprendemos?

Já sabemos que:

- programação é dar instruções ao computador;
- Python é uma linguagem de programação;
- `print()` mostra informação;
- texto fica normalmente entre aspas;
- números podem ser usados em contas;
- variáveis guardam valores;
- `input()` recebe respostas;
- `int()` transforma uma resposta em inteiro;
- `float()` transforma uma resposta em decimal;
- erros fazem parte da aprendizagem.

## 2. Exercício de aquecimento

O que aparece no ecrã?

```python
print("Olá!")
```

Resposta: aparece a palavra Olá!.

## 3. Variáveis

O que aparece?

```python
nome = "Lina"
print(nome)
```

Resposta: Lina.

## 4. Contas

O que aparece?

```python
a = 4
b = 6
print(a + b)
```

Resposta: 10.

## 5. Entrada

Completa:

```python
nome = ______("Qual é o teu nome? ")
print("Olá,", nome)
```

A função correta é `input`.

## 6. Conversão

Completa:

```python
idade = ______(input("Idade: "))
```

A função correta é `int`.

## 7. Exercícios práticos

### Exercício 1 — Saudação
Pede o nome e mostra uma saudação.

### Exercício 2 — Próximo ano
Pede a idade e calcula a idade no próximo ano.

### Exercício 3 — Soma
Pede dois números inteiros e mostra a soma.

### Exercício 4 — Multiplicação
Pede dois números inteiros e mostra o produto.

### Exercício 5 — Perfil
Pede nome, idade e cidade e mostra tudo.

### Exercício 6 — Mensagem
Pede uma palavra e mostra uma frase usando essa palavra.

## 8. Mini projeto 🛠️

### Cartão de apresentação

Cria um programa que pergunte:

- nome;

- comida favorita.

```
Idade: ...

```

## 9. Desafio final do volume ⭐⭐⭐

Cria um programa chamado **Conhece-me**.

Ele deve:

1. perguntar o nome;
2. perguntar a idade;
3. perguntar a cidade;
4. perguntar uma atividade favorita;
5. mostrar uma apresentação organizada;
6. calcular a idade no próximo ano.

Não copies tudo de uma vez.

Constrói o programa por partes.
