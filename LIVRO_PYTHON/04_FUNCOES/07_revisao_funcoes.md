## O que já sabemos?

Agora sabemos:

- criar funções com `def`;
- chamar funções;
- usar parâmetros;
- enviar argumentos;
- devolver resultados com `return`;
- usar valores padrão;
- entender escopo;
- trabalhar com listas dentro de funções.

## Exercício 1

Crie:

```python
def dobro(numero):
    return numero * 2
```

Teste com cinco números.

## Exercício 2

Crie uma função que receba três números e devolva a média.

## Exercício 3

Crie uma função que receba uma lista e conte quantos valores são positivos.

## Mini-projeto ⭐

Faça uma calculadora organizada por funções.

Crie uma função para cada operação:

```python
somar()
subtrair()
multiplicar()
dividir()
```

Depois crie um pequeno menu para escolher a operação.
