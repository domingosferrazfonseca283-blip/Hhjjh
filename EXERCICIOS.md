# Exercícios de Python

## Regra

Primeiro pensa. Depois escreve. Executa. Observa. Corrige. Tenta novamente.

## 🟢 Nível fácil

1. Mostra o teu nome no ecrã.
2. Mostra uma frase sobre porque queres aprender Python.
3. Cria uma variável para o teu nome e outra para a tua idade.
4. Mostra as duas variáveis.
5. Pede o nome ao utilizador e mostra uma saudação.

## 🟡 Nível médio

1. Lê dois números e calcula a soma.
2. Diz se um número é positivo, negativo ou zero.
3. Diz se um número é par ou ímpar.
4. Mostra os números de 1 a 10.
5. Cria uma função que calcule uma média.
6. Cria uma lista de nomes e percorre-a.
7. Conta palavras de uma frase.
8. Cria uma agenda usando um dicionário.

## 🔴 Desafios

1. Cria uma calculadora de terminal.
2. Cria uma lista de tarefas.
3. Cria um jogo de perguntas e respostas.
4. Guarda dados num ficheiro JSON.
5. Cria uma agenda de contactos.
6. Cria uma pequena API.
7. Cria uma aplicação que use uma base de dados.
8. Projeto final: junta várias ideias do curso numa aplicação útil.

## Para cada exercício

- Explica o problema com palavras simples.
- Divide-o em passos.
- Escreve pouco código de cada vez.
- Testa.
- Lê os erros.
- Melhora a solução.
