# Python Sem Medo — Do Zero Absoluto ao Python Avançado

**Autor:** Domingos Ferraz Fonseca

## Estrutura

250 aulas × 4 páginas = 1.000 páginas.

A regra pedagógica é simples: explicar primeiro, mostrar código depois, explicar cada linha, praticar e só então aumentar a dificuldade.

## Índice

Aulas progressivas desde programação e Python até objetos, testes, async, concorrência, performance, arquitetura e internals do Python.

## Primeiro exemplo

    print("Olá, mundo!")

`print()` pede ao Python para mostrar uma mensagem no ecrã. O texto está entre aspas porque é texto.

## Como estudar

Escreve os exemplos. Muda uma coisa de cada vez. Executa. Observa. Se der erro, lê a mensagem. Depois tenta novamente.
