## Exemplo

### Projeto de Deep Learning

Fluxo principal:

**problema → dados → preparação → modelo → treino → avaliação**

### Exercícios

1. Explica o conceito com as tuas palavras.
2. Dá um exemplo de utilização.
3. Indica uma dificuldade que pode aparecer.
4. Desenha o fluxo no papel.

### Desafio

Planeia uma pequena experiência de Deep Learning, indicando o problema, os dados, o modelo e a métrica que usarias.
