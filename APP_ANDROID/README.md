# 📱 Aplicativo Android — Curso-Livro de Python

**Autor:** Domingos Ferraz Fonseca

Este projeto transforma o conteúdo de LIVRO_PYTHON em um aplicativo Android de leitura **offline**.

## Como funciona

- O livro é copiado para os assets durante a compilação.
- O aplicativo usa uma WebView local.
- Depois de instalado, não precisa de GitHub ou Internet para ler o conteúdo.
- Os diagramas e imagens do livro também são empacotados.
- A pesquisa funciona dentro do aplicativo.

## Gerar o APK

O repositório contém uma configuração para compilação automática pelo GitHub Actions.

O APK de teste será gerado pelo workflow quando executado.

## Importante

Este diretório é o projeto-fonte do aplicativo. O APK é o ficheiro instalável que será produzido pela compilação.
